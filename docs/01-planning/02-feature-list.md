## 1. Core 기능 (MVP - 반드시 구현)

### 1.1 법률 리서치 Assistant

**설명**: 변호사가 자연어로 질문하면 관련 법령, 판례, 법리를 검색·요약하여 제공하는 기능

**AI Agent 동작 방식**:
1. 사용자 질문을 법률 쿼리로 파싱 (쟁점, 법률 분야, 관할 추출)
2. ResearchAgent가 법령 DB(국가법령정보센터), 판례 DB(대법원 종합법률정보)에 병렬 쿼리
3. 검색 결과를 관련도 순으로 랭킹 및 요약
4. 변호사에게 핵심 판시 사항, 적용 법조문, 유사 사건 목록 리포트 생성
5. 후속 질문 처리 (멀티턴 대화)

---

### 1.2 계약서 검토 및 리스크 분석

**설명**: 계약서 파일(PDF, DOCX)을 업로드하면 불리한 조항, 누락 조항, 리스크 항목을 탐지하고 수정 제안을 제공

**AI Agent 동작 방식**:
1. DocumentAnalysisAgent가 파일을 파싱하여 조항별로 구조화
2. 각 조항을 표준 계약서 템플릿 및 판례 기반 리스크 기준과 비교
3. 리스크 레벨(High/Medium/Low) 분류 및 플래그 표시
4. 수정 제안 문구 자동 생성
5. 최종 검토 리포트 (위험 조항 요약 + 권고 사항) 출력

---

### 1.3 계약서 초안 작성

**설명**: 계약 유형과 주요 조건을 입력하면 표준 계약서 초안을 자동 생성

**AI Agent 동작 방식**:
1. 사용자로부터 계약 유형(NDA, 용역계약, 매매계약 등), 당사자 정보, 핵심 조건 수집
2. DraftingAgent가 해당 계약 유형의 표준 템플릿 로드
3. 입력된 조건을 반영하여 조항 맞춤 생성
4. 한국 법률 준거 조항 자동 삽입 (준거법, 관할법원 등)
5. DOCX/PDF 형태로 다운로드 제공

---

### 1.4 마감일 및 기일 관리

**설명**: 사건별 법원 기일, 서면 제출 기한, 내부 마감일을 등록·추적·알림하는 기능

**AI Agent 동작 방식**:
1. 사용자가 사건 정보 및 기일을 입력하거나 법원 문서에서 자동 추출
2. DeadlineAgent가 기일 목록을 캘린더 DB에 저장
3. 마감 D-7, D-3, D-1 자동 알림 (이메일/앱 푸시)
4. 기일 충돌(같은 날 여러 기일) 감지 및 경고
5. 대시보드에 우선순위 순으로 업무 목록 표시

---

### 1.5 사건 문서 관리

**설명**: 사건별 문서를 업로드·분류·검색할 수 있는 통합 문서 저장소

**AI Agent 동작 방식**:
1. 업로드된 문서를 DocumentClassifierAgent가 자동 분류 (소장, 답변서, 증거, 판결문 등)
2. OCR 처리로 스캔 문서도 검색 가능하게 텍스트 추출
3. 사건번호, 당사자, 날짜, 문서 유형으로 태깅
4. 자연어 검색 ("이 사건에서 제출한 준비서면 모두 보여줘") 지원
5. 문서 버전 이력 관리

---

### 1.6 법원 서면 초안 작성

**설명**: 소장, 답변서, 준비서면 등 법원 제출 서면의 초안을 자동 생성

**AI Agent 동작 방식**:
1. 사용자가 사건 개요, 청구 취지, 주요 주장 사실을 입력
2. LegalDraftingAgent가 해당 서면 유형의 법원 양식 구조 로드
3. 관련 판례 및 법령을 자동 인용하여 법리 논거 구성
4. 법원 제출 형식(항목 번호, 날짜 형식 등)에 맞게 포맷팅
5. 변호사 검토 후 수정 → 최종본 생성

---

## 2. Advanced 기능 (2차 릴리즈)

### 2.1 청구서 자동 생성 (Billing Automation)

**설명**: 업무별 시간 기록을 기반으로 클라이언트 청구서를 자동 생성

**AI Agent 동작 방식**:
1. TimeTrackerAgent가 업무 수행 시간을 자동 또는 수동으로 기록
2. 사건별 시간 합산 및 수임료 단가 적용
3. 청구서 양식(PDF)으로 자동 생성
4. 이메일 발송 및 납부 현황 추적

---

### 2.2 클라이언트 커뮤니케이션 자동화

**설명**: 클라이언트 상담 내용 요약, 이메일 초안, 진행 상황 보고서 자동 생성

**AI Agent 동작 방식**:
1. 상담 메모 또는 녹취록을 입력하면 CommunicationAgent가 핵심 내용 요약
2. 클라이언트에게 보낼 이메일 초안 자동 생성 (법률 의견서, 안내 이메일)
3. 사건 진행 단계에 따른 정기 보고서 자동 생성
4. 클라이언트 포털에서 진행 상황 실시간 공유

---

### 2.3 법령 모니터링 및 컴플라이언스 알림

**설명**: 사용자의 업무 분야와 관련된 법령 개정 사항을 자동으로 모니터링하고 알림

**AI Agent 동작 방식**:
1. LegalMonitorAgent가 국가법령정보센터 개정 공포 피드를 주기적으로 수집
2. 사용자 설정 관심 분야(부동산, 노동, 세무 등)와 매칭
3. 영향 분석 요약 리포트 자동 생성 ("이 개정이 진행 중인 사건에 미치는 영향")
4. 이메일/앱 알림 발송

---

### 2.4 M&A Due Diligence 지원

**설명**: 다수의 계약서와 기업 문서를 일괄 업로드하면 이슈 요약 및 체크리스트 자동 생성

**AI Agent 동작 방식**:
1. 대량 문서 병렬 처리 (수십~수백 건)
2. DueDiligenceAgent가 문서 유형별 분류 및 이슈 추출
3. 리스크 매트릭스 생성 (법적 리스크, 재무 리스크, 운영 리스크)
4. 표준 Due Diligence 체크리스트 자동 완성

---

### 2.5 팀 협업 기능

**설명**: 소형 로펌에서 구성원 간 사건 공유, 업무 배정, 문서 협업을 지원

**AI Agent 동작 방식**:
1. 사건별 담당 변호사 및 보조 인력 배정
2. CollaborationAgent가 사건 진행 현황을 팀원 간 공유
3. 문서 공동 편집 및 댓글 기능
4. 업무 부하 모니터링 및 재배분 제안

## 4. 주요 사용자 시나리오 (User Story)

### 시나리오 1: 긴급 판례 리서치

**User Story**:
> 개인 변호사로서 나는 내일 오전 선고 기일을 앞두고 유사 판례를 빠르게 찾고 싶다. 왜냐하면 최후 변론에서 유리한 판례를 추가로 인용해야 하기 때문이다.

**AI Agent 동작 흐름**:
1. 변호사가 채팅창에 사건 개요와 핵심 쟁점을 입력 ("임금체불 관련 포괄임금제 무효 판례 찾아줘")
2. ResearchAgent가 쟁점 키워드 추출 → 대법원 판례 DB 및 하급심 판례 검색 (병렬)
3. 관련도 상위 10건 판례 요약 카드 생성 (사건번호, 판시 요지, 원문 링크)
4. "이 중 가장 강력한 판례 3건으로 변론 요지서 초안에 인용할 수 있는 문단을 작성해줘" 요청 처리
5. 인용 문단 초안 생성 → 변호사가 복사하여 서면에 바로 사용

---

### 시나리오 2: 계약서 검토 의뢰 대응

**User Story**:
> 소형 로펌 소속 변호사로서 나는 클라이언트가 보내온 50페이지 용역계약서를 1시간 안에 검토하고 싶다. 왜냐하면 오늘 오후 클라이언트 미팅에서 협상 포인트를 제시해야 하기 때문이다.

**AI Agent 동작 흐름**:
1. 변호사가 계약서 PDF를 업로드
2. DocumentAnalysisAgent가 PDF 파싱 → 조항별 구조화 (약 2분 소요)
3. 각 조항에 리스크 레벨 자동 태깅:
   - High Risk: 일방적 손해배상 조항, 무제한 책임 조항
   - Medium Risk: 지식재산권 귀속 조항, 계약 해지 요건
   - Low Risk: 일반 고지 조항
4. 우선순위 협상 포인트 5개 자동 선별 및 대안 문구 제안
5. 변호사가 검토 리포트를 PDF로 저장 → 미팅 자료로 활용

---

### 시나리오 3: 마감일 관리 및 알림

**User Story**:
> 여러 사건을 동시에 담당하는 변호사로서 나는 이번 주 내에 처리해야 할 법원 기일과 서면 제출 기한을 한눈에 보고 싶다. 왜냐하면 기일을 놓치면 의뢰인에게 돌이킬 수 없는 피해를 주기 때문이다.

**AI Agent 동작 흐름**:
1. 변호사가 법원 결정문(기일 지정 통지서)을 업로드 또는 직접 입력
2. DeadlineAgent가 문서에서 날짜/기일 정보 자동 추출 및 캘린더에 등록
3. 대시보드에 이번 주 마감 사항 우선순위 순 표시
4. D-7(1주일 전): "다음 주 금요일까지 준비서면 제출 기한입니다" 이메일 알림
5. D-1(전날): 앱 푸시 알림 + 필요 문서 체크리스트 자동 표시
6. 기일 충돌 감지 시 자동 경고 및 일정 조율 제안

---

### 시나리오 4: 표준 계약서 신속 작성

**User Story**:
> 스타트업 클라이언트를 담당하는 변호사로서 나는 NDA와 프리랜서 용역계약서를 오늘 안에 작성해서 클라이언트에게 보내고 싶다. 왜냐하면 클라이언트가 내일 계약 서명을 해야 하기 때문이다.

**AI Agent 동작 흐름**:
1. 변호사가 계약 유형 선택 (NDA), 당사자 정보 입력 (회사명, 대표자, 목적 등)
2. DraftingAgent가 NDA 표준 템플릿 로드
3. 입력 정보 반영 + 한국법 준거 조항(준거법, 관할법원 서울중앙지방법원 등) 자동 삽입
4. 초안 생성 완료 (약 1분) → 에디터에서 인라인 수정 가능
5. 용역계약서도 동일하게 반복 처리 (총 2건 약 5분 완료)
6. DOCX 파일 다운로드 → 클라이언트에게 이메일 전송

---

### 시나리오 5: 사건 문서 검색 및 참조

**User Story**:
> 1년 전에 처리한 사건의 준비서면을 참고해야 하는 변호사로서 나는 특정 법리 주장이 담긴 문서를 즉시 찾고 싶다. 왜냐하면 동일한 법리를 현재 진행 중인 사건에 적용하고 싶기 때문이다.

**AI Agent 동작 흐름**:
1. 변호사가 자연어로 검색 ("포괄임금제 무효 주장한 2025년 사건 준비서면")
2. DocumentSearchAgent가 전체 문서 DB를 시맨틱 검색
3. 관련 문서 목록 및 해당 조항/문단 미리보기 제공
4. 변호사가 문서 클릭 → 해당 부분 강조 표시로 바로 확인
5. "이 부분을 현재 사건에 맞게 수정해줘" 요청 시 DraftingAgent가 맞춤 수정본 생성

## 5. AI Agent 종류 정의

### 5.1 ResearchAgent (법률 리서치 Agent)

| 항목 | 내용 |
|------|------|
| 역할 | 법령, 판례, 학설 검색 및 요약 |
| 입력 | 자연어 질문, 쟁점 키워드, 사건 개요 |
| 출력 | 관련 판례 목록 (요약 카드), 법령 조문, 법리 정리 리포트 |
| 연동 데이터 소스 | 국가법령정보센터 API, 대법원 종합법률정보, 법제처 |
| 특이사항 | 멀티턴 대화 지원, 검색 결과 랭킹 (관련도 + 최신성) |

---

### 5.2 DocumentAnalysisAgent (문서 분석 Agent)

| 항목 | 내용 |
|------|------|
| 역할 | 계약서 및 법률 문서의 조항 분석, 리스크 분류 |
| 입력 | PDF/DOCX 파일, 분석 목적 (검토/비교/요약) |
| 출력 | 조항별 리스크 레벨 태그, 수정 제안 문구, 검토 리포트 |
| 연동 데이터 소스 | 내부 표준 계약서 템플릿 DB, 판례 기반 리스크 기준 DB |
| 특이사항 | OCR 처리 포함, 50페이지 이상 대용량 문서 처리 가능 |

---

### 5.3 DraftingAgent (문서 초안 작성 Agent)

| 항목 | 내용 |
|------|------|
| 역할 | 계약서, 법원 서면, 이메일 등 법률 문서 초안 생성 |
| 입력 | 문서 유형, 당사자 정보, 핵심 조건, 주장 사실 |
| 출력 | DOCX/PDF 형태의 문서 초안, 인라인 편집 가능한 에디터 뷰 |
| 연동 데이터 소스 | 계약서 템플릿 라이브러리, 법원 서면 양식 DB, ResearchAgent |
| 특이사항 | ResearchAgent와 연동하여 판례 인용 자동 삽입 |

---

### 5.4 DeadlineAgent (마감일 관리 Agent)

| 항목 | 내용 |
|------|------|
| 역할 | 법원 기일, 서면 제출 기한, 내부 마감일 추적 및 알림 |
| 입력 | 법원 문서 (기일 통지서), 사용자 직접 입력, 캘린더 연동 |
| 출력 | 기일 캘린더, 우선순위 업무 대시보드, 이메일/푸시 알림 |
| 연동 데이터 소스 | 내부 캘린더 DB, 이메일 서비스, 앱 푸시 서비스 |
| 특이사항 | 문서에서 날짜 자동 추출, 기일 충돌 감지 |

---

### 5.5 DocumentClassifierAgent (문서 분류 Agent)

| 항목 | 내용 |
|------|------|
| 역할 | 업로드된 문서를 유형별로 자동 분류 및 태깅 |
| 입력 | PDF/DOCX/이미지 파일, 사건 컨텍스트 |
| 출력 | 문서 유형 태그 (소장/답변서/판결문/증거 등), 핵심 메타데이터 |
| 연동 데이터 소스 | 내부 문서 저장소 (사건별 폴더 구조) |
| 특이사항 | OCR 처리, 스캔 문서 처리 가능 |

---

### 5.6 DocumentSearchAgent (문서 검색 Agent)

| 항목 | 내용 |
|------|------|
| 역할 | 저장된 문서에 대한 자연어 시맨틱 검색 |
| 입력 | 자연어 검색 쿼리 |
| 출력 | 관련 문서 목록, 해당 문단 미리보기, 원문 링크 |
| 연동 데이터 소스 | 벡터 DB (문서 임베딩 저장), 내부 문서 저장소 |
| 특이사항 | 키워드 검색 + 시맨틱 검색 하이브리드 방식 |

---

### 5.7 LegalMonitorAgent (법령 모니터링 Agent) — Phase 2

| 항목 | 내용 |
|------|------|
| 역할 | 법령 개정 사항 자동 수집 및 영향 분석 |
| 입력 | 사용자 설정 관심 분야 키워드, 관련 사건 목록 |
| 출력 | 개정 법령 요약 리포트, 영향 분석, 알림 |
| 연동 데이터 소스 | 국가법령정보센터 개정 공포 피드 (RSS/API) |
| 특이사항 | 스케줄 기반 자동 실행 (일 1회), 관련 사건 연동 분석 |

### 5.8 OrchestratorAgent (오케스트레이터 Agent)

| 항목 | 내용 |
|------|------|
| 역할 | 사용자 요청을 해석하여 적합한 하위 Agent에 작업 분배 및 결과 통합 |
| 입력 | 사용자 자연어 요청 |
| 출력 | 통합 응답 (복수 Agent 결과를 하나의 워크플로우로 결합) |
| 연동 데이터 소스 | 모든 하위 Agent |
| 특이사항 | 복잡한 요청 ("이 계약서 검토하고, 판례도 찾아서 의견서 써줘")을 자동으로 다단계 워크플로우로 분해 |
