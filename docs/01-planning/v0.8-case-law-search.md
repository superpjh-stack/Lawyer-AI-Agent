# v0.8 Plan: 판례 원문 검색 (Case Law Search)

## 1. 개요

기존 "판례 검색" 기능을 "판례 요약검색"으로 레이블 변경하고, 국가법령정보 OpenAPI를 활용한 "판례 원문 검색" 기능을 신규 추가한다.

## 2. 기능 요구사항

### 2.1 기존 기능 변경
| ID | 요구사항 | 우선순위 |
|----|----------|----------|
| R-01 | "판례 검색" 탭 레이블을 "판례 요약검색"으로 변경 | P0 |
| R-02 | 사이드바 "법률 리서치" 하위에 "판례 원문 검색" 메뉴 추가 | P0 |

### 2.2 판례 원문 검색 (신규)
| ID | 요구사항 | 우선순위 |
|----|----------|----------|
| R-03 | 국가법령정보 API 연동 키워드 검색 | P0 |
| R-04 | 판례 원문 상세 조회 (전문 표시) | P0 |
| R-05 | AI 요약 비교 (원문 옆에 GPT-4o 요약 표시) | P1 |
| R-06 | 판례 북마크/저장 (DB 저장, 케이스 연결) | P1 |
| R-07 | pgvector 시맨틱 검색 (의미 기반 유사 판례) | P2 |
| R-08 | API key 없을 시 Mock 데이터 graceful fallback | P0 |
| R-09 | 모바일 반응형 UI | P0 |

## 3. 범위 (Scope)

### In Scope
- 국가법령정보 OpenAPI 래퍼 클라이언트 (`src/lib/law-api.ts`)
- CaseLawBookmark Prisma 모델 추가
- API 라우트: `/api/research/case-law`, `/api/research/case-law/[id]`, `/api/research/bookmarks`, `/api/research/bookmarks/[id]`
- 페이지: `/research/case-law` (목록), `/research/case-law/[id]` (상세+AI요약)
- 사이드바 메뉴 구조 변경
- 리서치 메인 페이지 탭 이름 업데이트

### Out of Scope
- 법령 본문 검색 (별도 feature)
- 판례 PDF 다운로드
- 판례 기반 자동 문서 생성

## 4. 기술 의존성
- 국가법령정보 OpenAPI: `https://www.law.go.kr/DRF/lawSearch.do` (판례 검색)
- OpenAI GPT-4o: AI 요약 생성
- pgvector: 시맨틱 검색 (PostgreSQL extension)
- Prisma: CaseLawBookmark 모델

## 5. 성공 기준
- 키워드 검색으로 판례 목록 표시
- 판례 원문 전문 조회 가능
- AI 요약과 원문 나란히 비교 가능
- 북마크 저장/삭제 동작
- API key 미설정 시에도 Mock 데이터로 정상 작동
- 모바일에서 정상 레이아웃
