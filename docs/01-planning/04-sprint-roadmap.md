## Sprint 1: 기반 인프라 & 판례/법령 리서치 AI

### 목표
사용자 인증, 사건 관리 기반 구조를 구축하고, GPT-4o 기반 판례/법령 자연어 검색 기능을 제공하여 LexAgent의 핵심 가치를 빠르게 증명한다.

### 구현 기능 목록

**인프라 / 인증**
- 변호사 회원가입 / 로그인 (이메일 + 비밀번호)
- 사건(Case) 생성 / 조회 / 수정 / 삭제 기본 CRUD
- 사건 메타데이터 관리 (사건번호, 의뢰인명, 사건 유형, 상태)

**판례/법령 리서치 AI**
- 자연어 쿼리 입력 → GPT-4o 기반 관련 판례/법령 검색 및 결과 반환
- 판례 요약 자동 생성 (쟁점, 판시 사항, 핵심 의미 3-5줄)
- 법제처 국가법령정보센터 API 연동 (현행 법령 조회)
- 검색 결과 사건에 연결 저장 (북마크)
- 리서치 히스토리 조회

### 완료 기준 (Definition of Done)

- [ ] 변호사가 회원가입 후 로그인하여 사건을 생성할 수 있다
- [ ] 자연어 질문 입력 시 관련 판례 요약 3건 이상 반환된다
- [ ] 법제처 API 연동으로 현행 법령 조문 조회가 가능하다
- [ ] 검색 결과를 특정 사건에 저장할 수 있다
- [ ] GPT-4o API 응답 시간 평균 10초 이내
- [ ] 단위 테스트 커버리지 70% 이상

### 예상 산출물

- **화면**: 로그인/회원가입, 사건 목록, 사건 상세, 리서치 검색 페이지
- **API**: `/auth/*`, `/cases/*`, `/research/query`, `/research/history`
- **DB 스키마**: `users`, `cases`, `research_queries`, `research_results`
- **외부 연동**: 법제처 Open API, OpenAI GPT-4o API

### 기술 난이도: **중**

## Sprint 2: 서면 초안 자동 생성

### 목표
사건 정보와 리서치 결과를 바탕으로 소장, 준비서면, 의견서 초안을 GPT-4o로 자동 생성하여 서면 작성 시간을 50% 이상 단축한다.

### 구현 기능 목록

**서면 초안 생성**
- 서면 유형 선택 (소장 / 답변서 / 준비서면 / 고소장 / 의견서 / 계약서 등)
- 사건 정보 + 주요 사실관계 입력 → GPT-4o 초안 생성
- 판례 인용 자동 삽입 (Sprint 1 리서치 결과 연동)
- 초안 편집기 (리치 텍스트 에디터)
- 버전 관리 (초안 v1, v2... 이력 유지)
- Word(.docx) / PDF 내보내기

**서면 완성도 체크리스트**
- 서면 유형별 필수 구성 요소 자동 검증 (청구 취지, 청구 원인 등)
- 누락 항목 알림

**서면 템플릿 관리**
- 사용자 정의 템플릿 저장
- 기본 제공 템플릿 (민사소장, 형사고소장, 행정심판청구서 등 5종)

### 완료 기준 (Definition of Done)

- [ ] 사건 정보 입력 후 서면 초안이 30초 이내 생성된다
- [ ] 생성된 초안에 관련 판례 인용이 1건 이상 자동 포함된다
- [ ] 편집기에서 초안을 수정하고 저장할 수 있다
- [ ] Word / PDF 형식으로 내보내기가 정상 동작한다
- [ ] 서면 유형별 체크리스트가 자동으로 표시된다
- [ ] 내부 변호사 테스터 2명 이상 초안 품질 3.5/5.0 이상 평가

### 예상 산출물

- **화면**: 서면 생성 마법사, 서면 편집기, 서면 목록, 템플릿 관리
- **API**: `/documents/generate`, `/documents/*`, `/templates/*`
- **DB 스키마**: `documents`, `document_versions`, `templates`
- **외부 연동**: OpenAI GPT-4o (스트리밍), docx 생성 라이브러리

### 기술 난이도: **상**

## Sprint 3: 기일 관리 & 사건 대시보드

### 목표
법원 기일을 체계적으로 관리하고 기일 전 준비 작업을 자동 리마인드하여 기일 실수를 90% 이상 감소시키며, 전체 사건 현황을 한눈에 볼 수 있는 대시보드를 제공한다.

### 구현 기능 목록

**기일 관리**
- 기일 등록 (사건 연결, 기일 유형, 법원, 날짜/시간)
- 캘린더 뷰 (월간 / 주간 / 일간)
- 기일 충돌 자동 감지 및 경고
- 기일 전 준비 체크리스트 자동 생성 (서면 제출, 증거 준비 등)

**알림 시스템**
- 기일 D-7, D-3, D-1 자동 이메일/앱 알림
- 서면 제출 마감일 알림
- 준비 체크리스트 미완료 항목 알림

**사건 대시보드**
- 전체 사건 현황 (진행 중 / 완료 / 대기)
- 이번 주 / 이번 달 기일 현황
- 사건별 진행 단계 시각화 (타임라인)
- 사건 검색 / 필터링 (사건 유형, 상태, 의뢰인)

### 완료 기준 (Definition of Done)

- [ ] 기일 등록 후 캘린더에 정상 표시된다
- [ ] 동일 시간대 기일 등록 시 충돌 경고가 표시된다
- [ ] 기일 D-7 이메일 알림이 정상 발송된다
- [ ] 대시보드에서 전체 사건 현황을 1초 이내 로드한다
- [ ] 사건 검색/필터 기능이 정상 동작한다

### 예상 산출물

- **화면**: 메인 대시보드, 캘린더 뷰, 기일 등록/편집, 사건 타임라인
- **API**: `/hearings/*`, `/notifications/*`, `/dashboard/summary`
- **DB 스키마**: `hearings`, `notifications`, `checklists`
- **외부 연동**: 이메일 발송 서비스 (SendGrid 또는 SES)

### 기술 난이도: **중**

## Sprint 4: 계약서 리스크 분석

### 목표
계약서 파일을 업로드하면 위험 조항을 자동으로 식별하고 협상 포인트를 도출하여 계약서 검토 시간을 70% 이상 단축한다.

### 구현 기능 목록

**계약서 업로드 & 파싱**
- PDF / Word 계약서 업로드
- 텍스트 추출 및 조항별 분리 파싱
- 계약서 유형 자동 분류 (임대차, 용역, 매매, NDA 등)

**리스크 자동 분석**
- GPT-4o 기반 위험 조항 자동 하이라이팅 (고/중/저 위험도 분류)
- 표준 조항 대비 수정/불리 조항 비교 분석
- 누락된 필수 조항 식별
- 협상 포인트 우선순위 자동 도출

**계약서 검토 보고서**
- 리스크 요약 보고서 자동 생성
- 조항별 의견 및 수정 제안 포함
- 보고서 PDF 내보내기

### 완료 기준 (Definition of Done)

- [ ] PDF / Word 계약서 업로드 후 텍스트 파싱이 정상 동작한다
- [ ] 위험 조항 분석 결과가 업로드 후 60초 이내 반환된다
- [ ] 고위험 조항 식별 정확도 내부 변호사 검토 기준 70% 이상
- [ ] 리스크 요약 보고서가 PDF로 내보내기된다
- [ ] 100페이지 이상 계약서 처리 시 오류 없이 동작한다

### 예상 산출물

- **화면**: 계약서 업로드, 리스크 분석 결과 뷰어, 보고서 미리보기
- **API**: `/contracts/upload`, `/contracts/analyze`, `/contracts/report`
- **DB 스키마**: `contracts`, `contract_clauses`, `risk_analyses`
- **외부 연동**: OpenAI GPT-4o, PDF 파싱 라이브러리 (PyMuPDF 등)

### 기술 난이도: **상**

## Sprint 5: 통합 완성 & 의뢰인 커뮤니케이션 지원

### 목표
전체 기능을 통합하여 안정적인 MVP를 완성하고, 사건 진행 보고서 자동 생성 및 의뢰인 커뮤니케이션 지원 기능을 추가하여 초기 유료 사용자 확보 준비를 완료한다.

### 구현 기능 목록

**의뢰인 커뮤니케이션 지원**
- 사건 진행 상황 요약 보고서 자동 생성 (의뢰인용 쉬운 언어)
- 법률 용어 → 일반 언어 자동 변환
- 자주 묻는 질문 응답 초안 자동 생성
- 의뢰인별 커뮤니케이션 히스토리 기록

**의뢰인 포털 (기본)**
- 의뢰인 계정 생성 (변호사가 초대)
- 사건 진행 현황 조회 (읽기 전용)
- 문서 공유 기능

**통합 & 안정화**
- 전체 기능 E2E 테스트
- 성능 최적화 (API 응답 시간, DB 쿼리 최적화)
- 에러 모니터링 설정 (Sentry 등)
- 사용자 온보딩 플로우 (가이드 투어)
- 초기 요금제 설정 (무료 체험 14일 + 유료 플랜)

### 완료 기준 (Definition of Done)

- [ ] 의뢰인용 진행 상황 보고서가 1분 이내 생성된다
- [ ] 의뢰인 포털에서 사건 현황 조회가 정상 동작한다
- [ ] E2E 테스트 주요 플로우 (리서치 → 서면생성 → 기일관리) 통과
- [ ] 평균 페이지 로드 시간 3초 이내
- [ ] 결제 연동 및 유료 플랜 전환 정상 동작
- [ ] 초기 베타 테스터 변호사 5명 이상 확보 및 온보딩 완료

### 예상 산출물

- **화면**: 의뢰인 보고서 생성, 의뢰인 포털, 온보딩 플로우, 요금제 페이지
- **API**: `/clients/*`, `/client-portal/*`, `/reports/client-summary`
- **DB 스키마**: `clients`, `client_portal_access`, `communication_history`
- **외부 연동**: 결제 시스템 (Stripe 또는 토스페이먼츠)

### 기술 난이도: **중**
