## 1. 전체 화면 흐름도 (User Flow)

### 1.1 인증 플로우

```
[랜딩 페이지]
      |
      |--[로그인 클릭]--> [로그인 페이지] --[성공]--> [대시보드]
      |                        |
      |                   [비밀번호 분실]--> [비밀번호 재설정]
      |
      |--[무료 시작 클릭]--> [회원가입 페이지] --[완료]--> [온보딩 투어] --> [대시보드]
```

### 1.2 핵심 업무 플로우

```
[대시보드]
      |
      |--[사건 관리]---> [사건 목록] --[사건 선택]--> [사건 상세]
      |                      |                           |
      |              [+ 새 사건 생성]            [리서치 연결 / 서면 연결]
      |
      |--[AI 채팅]----> [채팅 인터페이스]
      |                      |
      |              [도구 자동 호출: 판례 검색 / 법령 조회 / 문서 분석]
      |                      |
      |              [결과 + 인용 출처 표시]
      |
      |--[법률 리서치]--> [리서치 검색 페이지] --[결과 선택]--> [판례/법령 상세]
      |                        |
      |                  [사건에 북마크 저장]
      |
      |--[문서 초안]---> [서면 유형 선택] --> [사건 정보 입력] --> [AI 초안 생성]
      |                                                              |
      |                                                    [편집기] --> [내보내기(docx/pdf)]
      |
      |--[문서 관리]---> [문서 목록] --[업로드]--> [문서 분석 뷰어]
      |
      |--[기일 관리]---> [캘린더 뷰] --[기일 클릭]--> [기일 상세/편집]
      |                      |
      |              [+ 기일 등록] --> [기일 등록 폼]
      |
      |--[클라이언트]-> [의뢰인 목록] --> [의뢰인 상세]
```

### 1.3 계약서 리스크 분석 플로우 (Sprint 4)

```
[문서 관리] --[계약서 업로드]--> [업로드 & 파싱 중]
                                        |
                              [리스크 분석 결과 뷰어]
                                        |
                        [조항별 위험도 하이라이팅: 고/중/저]
                                        |
                              [보고서 생성 & PDF 내보내기]
```

## 3. 디자인 시스템 가이드

### 3.1 색상 팔레트

#### Primary: Navy

| 토큰 | Hex | 용도 |
|------|-----|------|
| `navy-900` | `#1e2060` | 주요 CTA 버튼, 사이드바 액티브, 로고 |
| `navy-800` | `#3232a5` | 호버 상태 |
| `navy-700` | `#3d3bcc` | 보조 강조 |
| `navy-500` | `#6066f4` | 포커스 링, 링크 |
| `navy-100` | `#e0e9ff` | 액티브 배경 (사이드바) |
| `navy-50` | `#f0f4ff` | 아주 연한 배경 강조 |
| `navy-950` | `#131440` | 최진하 다크 (버튼 텍스트 on gold) |

**그라디언트**: `gradient-navy` — `linear-gradient(135deg, #1e2060 0%, #3232a5 100%)`
→ 랜딩 Hero 배경, 스플래시 화면에 사용

#### Secondary: Gold

| 토큰 | Hex | 용도 |
|------|-----|------|
| `gold-400` | `#f4bb24` | 주요 CTA (무료 시작, 새 사건) |
| `gold-500` | `#e39f0f` | 호버 상태, 강조 텍스트 |
| `gold-300` | `#f7cf4d` | 아이콘 강조 |
| `gold-100` | `#fdf3c9` | 배지 배경 |
| `gold-50` | `#fefbec` | 알림/경고 배경 |

## 6. 접근성 & UX 원칙

### 접근성

- 모든 인터랙티브 요소에 `focus:ring-2 ring-navy-500` 포커스 링 적용
- 아이콘 전용 버튼에 `aria-label` 또는 `title` 속성 필수
- 색상만으로 상태를 구분하지 않음 (텍스트/아이콘 병행)
- 최소 터치 타겟: 44x44px (모바일)

### UX 원칙

1. **AI 보조 도구 명확화**: 모든 AI 생성 콘텐츠에 "AI 생성" 레이블 + 면책 문구
2. **점진적 공개**: 복잡한 기능(서면 생성, 리스크 분석)은 스텝 단위로 분리
3. **빠른 피드백**: 도구 실행 상태, 로딩, 완료 상태를 항상 시각적으로 표시
4. **사건 중심 네비게이션**: 어느 화면에서든 현재 연결된 사건을 컨텍스트로 표시
5. **오류 방지 우선**: 기일 충돌, 서면 필수 항목 누락 등 제출 전 검증
