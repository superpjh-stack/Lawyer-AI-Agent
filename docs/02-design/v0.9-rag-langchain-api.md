## 2. Knowledge Management APIs

### 2.1 POST `/api/knowledge/ingest`

단일 문서를 지식베이스에 임베딩.

**Request:**
```json
{
  "documentId": "string",       // Document.id (already uploaded)
  "docType": "contract",        // form | procedure | sentence_style | precedent | contract | law_article
  "practiceArea": "civil",      // civil | criminal | corporate | family | real_estate | labor | ip | administrative | general
  "shared": false               // true = 공용, false = 개인
}
```

**Response (200):**
```json
{
  "data": {
    "documentId": "clxyz123",
    "chunksCreated": 12,
    "embeddingStatus": "completed",
    "processingTime": 8500
  }
}
```

**Response (202 - async for large docs):**
```json
{
  "data": {
    "documentId": "clxyz123",
    "embeddingStatus": "processing",
    "message": "문서 임베딩이 진행 중입니다."
  }
}
```

**Error Responses:**
| Status | Condition |
|--------|-----------|
| 400 | Missing/invalid documentId, docType, or practiceArea |
| 404 | Document not found |
| 409 | Document already embedded (embeddingStatus = completed) |
| 413 | Document too large (> 20MB) |
| 500 | Embedding pipeline error |

---

### 2.2 POST `/api/knowledge/batch`

최대 20개 문서를 일괄 임베딩.

**Request:**
```json
{
  "documents": [
    {
      "documentId": "string",
      "docType": "contract",
      "practiceArea": "civil",
      "shared": false
    }
  ]
}
```

**Response (202):**
```json
{
  "data": {
    "batchId": "batch_abc123",
    "totalDocuments": 5,
    "status": "processing",
    "progress": []
  }
}
```

**Error Responses:**
| Status | Condition |
|--------|-----------|
| 400 | Empty array or > 20 documents |
| 400 | Invalid docType or practiceArea in any item |

## 3. Multi-step Agent APIs

### 3.1 POST `/api/agent/execute`

Multi-step 에이전트 실행 (SSE 스트리밍).

**Request:**
```json
{
  "taskType": "case_research",    // case_research | risk_analysis | document_draft
  "input": "임대차 계약 분쟁에 관한 소장을 작성해주세요. 임대인이 일방적으로 계약을 해지했습니다.",
  "conversationId": "conv_abc",   // optional: link to conversation
  "options": {
    "autoExecute": true,          // true = 모든 단계 자동 실행, false = 단계별 확인
    "practiceArea": "real_estate" // optional: scope search
  }
}
```

**Response (SSE Stream):**
```
Content-Type: text/event-stream

data: {"type":"agent_step","step":{"stepNumber":1,"stepName":"요청 분석","status":"running"}}

data: {"type":"agent_step","step":{"stepNumber":1,"stepName":"요청 분석","status":"completed","output":{"issue":"임대차계약 일방해지","keywords":["임대차","계약해지","일방적"]}}}

data: {"type":"agent_step","step":{"stepNumber":2,"stepName":"판례 검색","status":"running"}}

data: {"type":"tool_use","toolName":"search_cases"}

data: {"type":"tool_result","toolName":"search_cases","result":{"cases":[...]}}

data: {"type":"agent_step","step":{"stepNumber":2,"stepName":"판례 검색","status":"completed","output":{"casesFound":3}}}

data: {"type":"agent_step","step":{"stepNumber":3,"stepName":"관련 법령 검색","status":"running"}}

data: {"type":"tool_use","toolName":"search_laws"}

data: {"type":"agent_step","step":{"stepNumber":3,"stepName":"관련 법령 검색","status":"completed"}}

data: {"type":"agent_step","step":{"stepNumber":4,"stepName":"문서 초안 작성","status":"running"}}

data: {"type":"text","content":"소  장\n\n원    고: ..."}

data: {"type":"sources","documents":[{"title":"대법원 2020다12345","similarity":0.92}]}

data: {"type":"done","executionId":"exec_xyz789"}
```

**Response Headers:**
```
X-Execution-Id: exec_xyz789
```

## 5. Modified Endpoints

### 5.1 POST `/api/chat` (Modified)

**Changes:**
1. `RAGOrchestrator` 사용 (기존 `orchestratorAgent` 래핑)
2. `sources` SSE 이벤트 추가

```json

```

**New SSE Events:**
```
data: {"type":"sources","documents":[{"title":"매매계약서","chunkIndex":4,"similarity":0.89,"docType":"contract"}]}
```

### 5.2 POST `/api/documents/upload` (Modified)

**Request (modified - multipart/form-data):**
| Field | Type | Required | Description |
|-------|------|----------|-------------|
| file | File | Yes | 업로드 파일 |

### 5.3 GET `/api/research/case-law` (Modified)

**Query Parameters (added):**
| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| searchMode | string | keyword | [NEW] keyword / semantic / hybrid |

When `searchMode=semantic` or `hybrid`:
- Runs pgvector search on CaseLawBookmark embeddings
- If `hybrid`: merges with BM25 results via RRF

## 6. Common Response Patterns

### 6.1 Pagination

All list endpoints use consistent pagination:
```json
{
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 100,
    "totalPages": 5
  }
}
```

### 6.2 Error Format

```json
{
  "error": {
    "code": "KNOWLEDGE_NOT_FOUND",
    "message": "지식 엔트리를 찾을 수 없습니다.",
    "details": {}
  }
}
```

### 6.3 Error Codes

| Code | Status | Description |
|------|--------|-------------|
| VALIDATION_ERROR | 400 | 입력값 검증 실패 |
| UNAUTHORIZED | 401 | 인증 필요 |
| FORBIDDEN | 403 | 권한 없음 |
| KNOWLEDGE_NOT_FOUND | 404 | 지식 엔트리 없음 |
| DOCUMENT_NOT_FOUND | 404 | 문서 없음 |
| ALREADY_EMBEDDED | 409 | 이미 임베딩 완료 |
| FILE_TOO_LARGE | 413 | 파일 크기 초과 |
| RATE_LIMIT | 429 | 요청 제한 |
| EMBEDDING_FAILED | 500 | 임베딩 처리 실패 |
| AGENT_FAILED | 500 | 에이전트 실행 실패 |

## 8. Authentication

All endpoints require NextAuth session. User ID is extracted from `session.user.id`.

```typescript
const session = await auth();
if (!session?.user?.id) {
  return NextResponse.json(
    { error: { code: 'UNAUTHORIZED', message: '로그인이 필요합니다.' } },
    { status: 401 }
  );
}
const userId = session.user.id;
```
