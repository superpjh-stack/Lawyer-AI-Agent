# LexAgent v0.7 - AI Legal Q&A Planning (20 Questions & Answers)

> Phase: Design | Feature: RAG AI Q&A | Date: 2026-03-09

---

## Overview

This document defines 20 representative question types that the RAG-powered legal AI should handle well, along with expected answer structures. These serve as both design specifications and test cases for the v0.7 RAG system.

Questions are categorized by the type of knowledge retrieval required.

---

## Category A: Contract Review (계약서 검토)

### Q1. "이 계약서 검토해줘" (General Contract Review)

**Trigger**: User uploads a contract document and asks for review.

**RAG Behavior**:
- Retrieve: lawyer's past contract templates + standard clause patterns
- Compare uploaded contract against known templates

**Expected Answer Structure**:
```
## 계약서 검토 결과

### 1. 문서 개요
- 계약 유형: [용역계약/매매계약/임대차계약 등]
- 당사자: [갑/을 정보]
- 계약 기간: [시작일 ~ 종료일]

### 2. 주요 조항 분석
| 조항 | 내용 요약 | 리스크 수준 | 코멘트 |
|------|----------|:---------:|--------|
| 제3조 (대금 지급) | ... | 낮음 | 표준적 구조 |
| 제7조 (손해배상) | ... | 높음 | 일방적 책임 전가 우려 |

### 3. 리스크 포인트
- [높음] 제7조: 손해배상 책임이 을에게만 집중됨
  - 권고: 상호 과실 비율에 따른 배상으로 수정
- [중간] 제12조: 해지 통보 기간이 지나치게 짧음 (7일)
  - 권고: 최소 30일로 연장

### 4. 누락 조항 확인
- [ ] 비밀유지 조항 누락
- [ ] 분쟁 해결 조항 미흡 (관할법원 미지정)
- [x] 지식재산권 귀속 조항 있음

### 5. 종합 의견
[전체적인 리스크 평가 및 수정 권고 요약]

[출처: 표준 용역계약서 템플릿, 민법 제390조]
```

### Q2. "손해배상 조항의 유효성을 분석해줘" (Specific Clause Analysis)

**RAG Behavior**:
- Retrieve: relevant precedents on damage clause validity
- Retrieve: lawyer's notes on similar clauses

**Expected Answer Structure**:
```
## 손해배상 조항 유효성 분석

### 해당 조항 원문
> "을은 본 계약 위반 시 계약금의 300%를 갑에게 배상한다"

### 법적 분석
1. **약정 손해배상의 유효성** (민법 제398조)
   - 약정 손해배상액은 원칙적으로 유효
   - 다만 부당하게 과다한 경우 법원이 감액 가능

2. **판례 기준**
   - 대법원 2019다12345: 계약금 대비 300% 배상은 ...
   - 대법원 2020다67890: 손해배상 예정액의 적정성 판단 기준 ...

3. **유효성 판단**
   - 결론: [유효/무효/감액 가능성]
   - 근거: ...

[출처: 민법 제398조, 대법원 2019다12345 판결]
```

### Q6. "고소장 접수 후 수사 절차는?"

**Expected Answer Structure**:
```
## 고소장 접수 후 수사 절차

### 절차 흐름도
고소장 접수 → 사건 배당 → 수사 개시 → 피의자 조사 → 검찰 송치 → 기소/불기소 결정

### 각 단계 상세
1. **고소장 접수** (경찰서/검찰청)
   - 접수증 수령
   - 사건번호 부여 (약 1-2주)
2. **사건 배당**
   - 담당 수사관 지정
   - 기초 수사 착수
3. **수사 진행**
   - 참고인 조사
   - 피의자 소환 조사
   - 증거 수집
4. **결정**
   - 기소 / 불기소(혐의없음, 기소유예 등)
   - 불기소 시: 항고 → 재항고 → 재정신청

### 기간
- 일반: 3-6개월
- 복잡 사건: 1년 이상 가능

[출처: 형사소송법 제230조~제257조]
```
